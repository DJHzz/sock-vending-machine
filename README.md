# SockVend 云端贩卖机项目
# 🧦 SockVend - 云端自助贩卖机系统

> **纯 C 语言全栈开发 | LVGL 嵌入式前端 | 自研 Linux Socket 云服务端**


这是一个基于 **C 语言** 从零到一打造的自助贩卖机全栈开源项目。前端采用 **LVGL** 运行于 ARM 嵌入式开发板，后端采用 **原生 Linux Socket** 构建 HTTP 协议栈部署于阿里云 ECS，真正实现了“云边一体化”的软硬件结合。


## ✨ 核心功能

### 👤 消费者端 (LVGL 开发板)
*   **用户模块**：支持云端注册与登录验证。
*   **实时库存同步**：商品售罄时按钮自动同步置灰（Disabled），支持跨用户状态隔离。
*   **动态购物车**：支持多商品选购、数量增减，实时计算总价。
*   **防误触支付**：支付按钮内置 5 秒倒计时防误触机制。
*   **订单溯源**：一键查看云端存储的个人历史购买记录（日期、订单号、件数、总价）。

### 🛠️ 商家端 (命令行工具)
*   **中文名智能映射**：商家无需背记 ID，直接输入中文名（如“可乐”）即可定位商品。
*   **远程库存管理**：支持远程**入库（补货）**和**出库（损耗处理）**。
*   **实时盘点**：一键拉取并打印云端数据库中所有商品的实时库存表格。
*   **人性化排错**：出库时若库存不足，会明确提示具体商品名、当前库存和缺失数量。

### ☁️ 云端服务端 (C 语言后台)
*   **原生 HTTP 解析**：基于 Linux Socket 多进程（`fork`）模型，高并发处理客户端请求。
*   **杜绝超卖**：引入 SQLite 数据库事务（`BEGIN IMMEDIATE TRANSACTION`），确保并发下单时绝不多扣库存。
*   **全链路流水审计**：所有库存变动（用户购买 `sale`、商家入库 `restock`、出库 `manual_out`）均记录于 `stock_logs` 表，历史可溯源。

## 🧰 技术栈与架构

| 层级 | 使用技术 |
| :--- | :--- |
| **前端 UI** | LVGL v8.3 |
| **网络通信** | Linux 原生 Socket (自研 HTTP/1.1 协议栈) |
| **数据序列化** | cJSON |
| **后端架构** | 多进程 (fork) 并发模型 |
| **数据存储** | SQLite 3 (支持 ACID 事务) |
| **云环境** | 阿里云 ECS (Ubuntu 20.04) |
| **开发工具** | VS Code + WSL 2 (交叉编译至 ARM 开发板) |
